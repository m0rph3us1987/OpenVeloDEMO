# Implementation Plan: Fix `npm error Missing script: "build"`

## 1. Investigation Summary
- **Error observed:** `npm error Missing script: "build"` produced by `npm run build` invoked at the repository root.
- **Root cause:** The root `package.json` (`/repo/package.json`) defines only `typecheck`, `test`, and `dev` scripts. It does not define a `build` script. When an external pipeline/CI step or implementer invokes `npm run build` at the root, npm fails because the script is missing. The workspace packages `apps/api` and `apps/web` each have their own `build` script, but npm workspaces do not auto-aggregate per-workspace scripts to the root.
- **Related observations:**
  - `apps/api/package.json` `build` is currently `tsc --noEmit` (which is functionally identical to `typecheck` and does not emit dist artifacts). For scaffolding this is acceptable but offers no actual build output.
  - `apps/web/package.json` `build` is `tsc -b && vite build` (correct for Vite; emits a `dist/` directory).
  - `packages/types/package.json` has no `build` script. For a TypeScript source-only shared package consumed via workspace TS sources, this is acceptable, but a build entrypoint would be conventional.
- **Acceptance constraint from the original Job:** This Job is scaffolding only; "no business logic, no sample data, no extra features beyond what is listed here". Adding root `build` orchestration is a small, justified correctness fix that keeps the pipeline green without introducing business features.

## 2. Impacted Files
- **To Modify:**
  - `/repo/package.json` — add a root `build` script that invokes the existing per-workspace `build` scripts via npm workspaces.
- **To Create:** none.
- **Optional / Discuss:** `apps/api/package.json` `build` script — keep as `tsc --noEmit` (no business logic expected at scaffold time) or replace with a real emit (`tsc -p tsconfig.json` emitting to `dist`). Defer to a later job if dist artifacts become required. Plan will keep current behavior to avoid scope creep.

## 3. Proposed Changes
1. **Add root `build` script:**
   - Edit `/repo/package.json` `scripts` to include:
     - `"build": "npm run build --workspaces --if-present"`
   - This sequentially runs the `build` script in every workspace that defines one. Currently:
     - `apps/api`: `tsc --noEmit` (typecheck-only, idempotent, no emitted artifacts — acceptable for scaffolding).
     - `apps/web`: `tsc -b && vite build` (emits `apps/web/dist`).
     - `packages/types`: no `build` script (skipped via `--if-present`).
   - The behavior matches npm workspaces conventions and does not add business features.
2. **Verification:**
   - `npm run build` at `/repo` exits 0.
   - Existing scripts remain intact: `npm run typecheck`, `npm run test`, `npm run dev`.
   - `apps/web/dist` is created; `apps/api` produces no dist (acceptable for scaffolding).

## 4. Test Strategy
- No new tests are required; this is a tooling/script fix only.
- Verification is the script invocation itself: `npm run build` at the root exits 0, and existing `npm run typecheck` / `npm run test` continue to pass.
- If the user later wants dist artifacts from `apps/api`, that belongs to a later job and is out of scope here.
